## Coffee-Shop ☕

- A modern coffee shop web application built with React and Vite.  
- It features a beautiful café-inspired UI, interactive menu cards, a working cart, and a simple checkout flow.

---

### Features

- Stylish coffee shop landing layout
- Coffee menu cards with prices and descriptions
- Add items to cart
- Remove individual items from cart
- Clear the full order
- Clickable cart counter at the top
- Smooth scroll to the order section
- Checkout popup with customer name input
- Order placed success message
- Responsive design for smaller screens

---

### How It Works

1. The coffee menu is stored in an array.
2. Clicking + adds a coffee to the cart.
3. The cart count updates automatically.
4. Clicking the cart button scrolls to the cart section.
5. Place Order opens a checkout modal.
6. Entering a name and confirming shows a success message and clears the cart.

---

### Notes

- This project uses a clean React state-based flow with useState.
- The brand text uses a moving marquee-style effect.
- The design is fully custom and does not depend on Bootstrap or Tailwind.
